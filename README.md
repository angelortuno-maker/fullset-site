# fullset-site
The public support, privacy and terms pages for the Fullset app, served by GitHub Pages:
https://angelortuno-maker.github.io/fullset-site/

Static HTML and CSS: no third-party requests, no app code, no keys. The one script is on `/action/`, the page behind
Fullset's account emails: it calls only Firebase's Identity Toolkit with the key the email link carries. Bebas Neue is under the SIL Open Font License (`fonts/OFL.txt`).
